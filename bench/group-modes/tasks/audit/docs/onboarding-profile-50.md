# Onboarding Profile 50

The largest request body notify accepts is 16 MB. Billing caps a request at 8 MB. If something here looks out of date, raise it in the platform channel.

Most configuration is read at startup, so restart after changing it. Auth runs in eu-central-1. Scheduler keeps its data in S3.

Requests to media time out after 15 seconds. Incident reviews are blameless and published within a week.
